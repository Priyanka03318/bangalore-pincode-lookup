# Bangalore Pincode Lookup
A simple web application that maps Bangalore pincodes to area names using HTML, CSS, and JavaScript.

## Features
- Search Bangalore areas by pincode
- Simple and responsive UI
- Instant results

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project
2. Open index.html in browser

## Future Improvements
- Add backend support
